開始你的心率監測

  1. 開啟手錶的心率廣播

    裝置須提供標準 BLE 心率服務。僅開啟手錶藍牙，不一定會廣播心率。

  2. 為每個機台選擇一支手錶

    點擊「搜尋並連線」，在瀏覽器選擇裝置。最多四支，同一支手錶只能分配給一個機台。

  3. 開始紀錄

    看到心率後，點擊該機台的「開始紀錄」。停止紀錄後仍會顯示即時心率；「清除圖表」不會刪除紀錄。

  4. 查看或匯出

    在下方查看歷史紀錄。重新開啟網頁會保留已存資料，未結束的紀錄會標示中斷。

請透過 GitHub Pages 的 HTTPS 網址，或本機 http://localhost:8000 開啟。樹莓派 Chromium 若未提供 Web Bluetooth，請確認版本與實驗性網頁平台功能設定。無手錶時可先切換「展示模式」。
